# Developer onboarding

Install Docker Desktop, clone repository, and run `docker compose up --build`. Open http://localhost:3000 and http://localhost:8000/docs.

For early smoke testing, create two small text-based PDFs containing lines such as `B21 W18X35` in the engineer PDF and `B21 W16X31` in the shop PDF. Upload both and confirm one mismatch appears.

Never upload confidential project drawings to the public repository.
